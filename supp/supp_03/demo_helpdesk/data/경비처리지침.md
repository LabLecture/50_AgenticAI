# (주)다희 경비처리지침

## 제1장 총칙

**제1조(목적)** 이 지침은 업무 수행 과정에서 발생하는 경비의 사용 기준과 정산 절차를 정한다.

**제2조(경비 사용 원칙)** ① 모든 경비는 업무 관련성이 입증되어야 한다.
② 법인카드 사용을 원칙으로 하며, 불가피하게 개인 비용으로 지출한 경우 영수증을 첨부하여 개인경비 정산을 신청한다.

## 제2장 법인카드

**제10조(법인카드 발급)** 팀장 이상 직책자와 영업·구매 담당자에게 법인카드를 발급한다. 그 외 직원은 부서 공용카드를 사용한다.

**제11조(사용 한도)**
| 항목 | 한도 |
|------|------|
| 직원 1인당 식대(중식) | 1만 2천 원/일 |
| 팀 회식 | 5만 원/인, 분기 1회 |
| 야근 식대 (20시 이후) | 1만 5천 원/일 |
| 국내 출장 숙박 | 12만 원/박 (서울·제주 15만 원) |
| 접대비 | 건당 30만 원 초과 시 사전 품의 |

**제12조(사용 금지 항목)** 다음 각 호에는 법인카드를 사용할 수 없다.
1. 주류 단독 구매 (회식 식대에 포함된 경우 제외)
2. 상품권·기프트카드 구매 (사전 품의 승인 건 제외)
3. 개인 용도의 물품 구매

## 제3장 정산 절차

**제20조(정산 기한)** ① 법인카드 사용 건은 **사용일로부터 7영업일 이내**에 그룹웨어 경비 시스템에 사용 내역과 증빙을 등록해야 한다.
② 개인경비는 지출일이 속한 달의 말일까지 신청하며, 익월 10일 급여 계좌로 지급한다.

**제21조(증빙 서류)** ① 3만 원 초과 지출은 반드시 적격 증빙(세금계산서·카드매출전표·현금영수증)을 첨부한다.
② 접대비는 참석자 명단과 업무 관련성을 기재한다.

**제22조(반려와 재신청)** 증빙 미비로 반려된 정산 건은 반려일로부터 5영업일 이내에 보완하여 재신청할 수 있으며, 기한 경과 시 개인 부담으로 처리한다.

## 제4장 출장 경비

**제30조(출장 경비 항목)** 출장 경비는 교통비·숙박비·일비·식비로 구성된다.
| 항목 | 기준 |
|------|------|
| 일비 (국내) | 2만 원/일 |
| 일비 (해외) | USD 50/일 |
| 항공 | 이코노미 (비행 8시간 초과 시 임원은 비즈니스) |
| KTX·고속버스 | 실비 |

**제31조(출장 경비 정산)** 출장 종료 후 5영업일 이내에 출장 결과 보고서와 함께 정산한다. 법인카드 사용분과 현금 지출분을 구분하여 등록한다.
